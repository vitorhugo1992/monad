# MONAD

A generative ambient music ecosystem in a single browser tab. Pixel-art phytoplankton live, divide, sync and die in a dark water column, and the music comes from their interactions. Nobody composes it: it emerges.

The user can watch (a tide pool) or play (a hand in the water). There is no mode switch. Playing is only a perturbation of the same system that is always running.

The author is a phytoplankton researcher. The biology is load-bearing, not decoration.

---

## Core principle: emergence over authorship

**Never script a behaviour. Find the local rule that produces it.**

- No archetypes, no hard-coded "pad cell / looper cell" types.
- No scripted events ("every 60s do a bloom"). Blooms, die-offs, rhythms and chords must come out of the rules below.
- No "if the player is playing, then..." branches. The player only changes the inputs to the same rules (where the water moves, which cells startle, which cells sound).
- If something needs to happen and no rule produces it, stop and propose a new **local rule** instead of an authored behaviour. Ask before adding it.

The music works through constraints, not randomness: one shared harmonic field, a voice budget, slow time constants. Freedom inside tight constraints is what makes emergent results beautiful rather than chaotic.

## Tech constraints

- **One file: `index.html`.** Vanilla JS, Canvas 2D, Web Audio API. No frameworks, no build step, no external scripts or fonts. The only other files are what installing needs (phase 8, author-approved): `manifest.webmanifest`, `sw.js` and `icons/`, and `facts.json`, the curiosity facts (author-approved 2026-10-22: loaded from the same site, cached offline, updated by reviewed pushes).
- Must run well on a phone in portrait and on desktop in landscape. Touch and mouse both work.
- **Seeded and deterministic.** All randomness goes through one seeded PRNG (mulberry32). The same seed must grow the same world. Without `?seed=` (or `?stress`, `?ff`, `?day`, `?season`) the page keeps **one world** that lives on between visits (random seed at birth, displayed, drawn again until it starts the world in the player's real season); with any of them it runs a scratch world that is never saved, so trying a seed never overwrites the kept one.
- **A saved world is the same world** (phase 8): the snapshot holds everything the rules read, including the PRNG states (mulberry32 keeps its state in the open), so a restored world steps on exactly as if it had never stopped. `tools/sim-check.mjs` checks the round trip.
- **Old saves must keep loading.** `tools/fixtures/` holds real saved worlds from earlier versions (`world-v2.bin`: seed 14, ~31 min, 178 cells with chains, elders, a cyst and a sunfish; `world-v3.bin`: the first with silica, viruses, hunting and newcomers; `world-v4.bin`: nine forms; `world-v5.bin`: the first with temperature, oxygen, marine snow, filamentous cyanobacteria and runoff; `world-v6.bin`: the first with salinity, tides and cysts made by living cells; `world-v7.bin`: the notebook revamp, whose recorder rows grew six columns; `world-v8.bin`: the first with seasons, whose world holds the day of the year it was born on; older saves wake in midsummer). Every `sim-check` run loads each one with the current code and lives it 5 more minutes: no crash, no NaN, nutrients finite, or the run fails. It also says whether the rules still grow the same world (a change there is allowed). Whenever the snapshot format changes (bump `persist.version`), add a fixture with `node tools/sim-check.mjs --save-fixture`; never delete old fixtures.
- **Tools for tuning** (`tools/`, Node, no browser; each file's header says how to run it): `sim-check.mjs` (many worlds: balance, music, conservation, determinism, saves; the full test is `node tools/sim-check.mjs 12 360`, ~40 min), `probe.mjs` (one world's water as a time series; PARAMS overrides apply before the code runs), `layers.mjs` (temperature profiles: mixed layer, thermocline, bottom layer), `bench.mjs` (speed in x real time, with the mean cell count: compare like with like, or against an older `index.html`), `cpu-top.mjs` (summarises a `--cpu-prof` profile). Tune against written targets, sweeping one parameter in parallel short runs, then confirm with one full run (author: no serial knob-turning). Screenshots: headless Edge (`msedge --headless=new --screenshot=... "file:///.../index.html?seed=2&ff=8400&zoom=4&at=60,20&notebook=4"`; `ff` fast-forwards s).
- **Fixed-timestep simulation** (30 ticks/s with an accumulator), decoupled from rendering. Required for determinism. **The slow water steps at 10 Hz** (2026-10-22, for speed): light, nutrient and silica diffusion, heat, salt, oxygen, marine snow, the cyanobacteria and the grazers step every 3rd tick with a 3x step, staggered over the three ticks. Cells, visitors and the mixing coefficients step every tick. Vertical mixing is implicit (backward Euler, Thomas algorithm), so it is stable at any step. Shared scratch (the mixing coefficients, the currents' departure points) is never carried from one tick or world to another. Speed: 112x to 220x real time on desktop (3 worlds, ~70 cells); the phone measured 96x before.
- All tunable numbers live in one `PARAMS` object at the top. No magic numbers scattered through the code.
- One `requestAnimationFrame` loop. No `setInterval`. Exception (phase 8): the catch-up worker's own loop.

### File sections (in order, marked `// ===== NAME =====`)
`PARAMS → RNG → Utils → Palette → Fields → Genome → Cells → Rules → Harmony → Persist → Audio → Render → Notebook → Input → Debug → Loop → Init`

## The world

A **side view of a water column**: a fixed world of 180 × 320 units (portrait, phone-first) with a sediment floor at the bottom. **The setting** (author, 2026-10-22) is a warm-temperate shelf sea at ~30 °N, like the East China Sea, about 60 m deep, living through the seasons of a year (until 2026-10-22 it was always summer). That is what the model already is: a warm surface over cold bottom water, *Trichodesmium* and *Prochlorococcus* carried in by a warm current, river runoff, strong tides and summer hypoxia. It is not the North Sea, whose bottom water is colder and whose surface is cooler. Light enters from the top. The surface is bright, the depths are dark. The world never changes size with the screen, so a seed grows the same world on every device.

### Fields (coarse grid, e.g. 24 × 40, bilinear sampling)
- **Light**: strongest at the top, decays with depth and under the living biomass above (self-shading), scaled by a slow day/night cycle (diel cycle; one "day" is 5 real minutes by default, `?day=5|10|30` picks 5, 10 or 30). Sunrise to sunset follows the season (10.3 h of 24 at the winter solstice to 14 h at the summer one), surface light follows `sqrt(sin)` (sharp twilights), and night keeps a faint moonlight at its real strength, about a millionth of noon (Gaston et al. 2013: seen, too faint to grow on). It follows the moon's phase (a synodic month of 29.5 days; a full moon 1.8 times the mean, a new moon a fifth; the seed sets the phase a world is born under). The world starts in early morning.
- **Seasons** (approved local rules, author, 2026-10-22): a true year of 365 game days (~30 real hours at 5-min days; the moon and the tides keep their true periods). A world starts on a day of the year set by its seed (`?season=winter|spring|summer|autumn` starts mid-season, development). Five things follow the day of the year, nothing else is seasonal and no season is scripted: **day length** (above); **the noon sun**, in winter 0.55 of its summer strength; **the air** the surface gives its heat to (7 °C to 18 °C, coldest 6 weeks after the winter solstice: the sea's lag), so winter cooling overturns the column and mixes it to the floor and summer stratifies it; **the wind**, whose targets are r^calm with calm 0.9 in winter (the monsoon: stormier) to 1.5 in summer (as before the seasons); and **storm runoff**, 0.3x to 1.7x as likely, wettest in early July (the flood season). The spring and autumn blooms, summer stratification and hypoxia must come out of these. Tuned with whole world-years (`node tools/sim-check.mjs 1 1830 <seed> --fast`, one world-year per process, ~30 min with 8 in parallel; sim-check reports each season: who led, peak, surface and bottom warmth, mixed to the floor, hypoxia, onsets). The first settings (summer calm 1.8, summer air 19) made summer dead zones 56–85% of summer and filamentous scums lead ~60% of it. Measured with these (8 world-years, 2026-10-22): winter mixed to the floor 83–90% of the time (surface ~10.4 over 10.3 °C), spring 13.6 °C, summer 20.5 °C over 11.8 °C (never mixed), autumn 16 °C; diatoms lead most winters and springs, summer is shared by filamentous cyanobacteria, diatoms, dinoflagellates and coccolithophores, autumn by diatoms, dinoflagellates, cryptophytes and green algae; leading over the year diatoms 27%, cryptophytes 22%, green algae 15%, dinoflagellates 14%, coccolithophores 12%, filamentous 9%, cyanobacteria 2%; bottom hypoxia 3–17% of the year (median ~9%), all in summer and autumn; no extinctions in the 7 that lived. Music is quieter in winter (~1.8 onsets/s; summer 2.3–2.8, the year ~2.2): fewer cells and long nights. **Born in the dark half of the year** a world is a little more fragile: of 200 seeds, 2 died out within 15 minutes of birth (their founders lysed before dividing), none when all were born in midsummer (author: accepted, extinction stays an ending).
- **Wind** (weather): a slow seeded process. Its target changes at random intervals (calm spells common, storms rarer; how rare follows the season) and the wind eases toward it. Strong wind drives upwelling (nutrient pulses). It also sets the sea state the renderer draws: wave height, how fast the water moves, refraction, and whether rays form.
- **Nutrients**: diffuse slowly, are consumed by cells, enter from the bottom (upwelling), and return when cells die (remineralisation). Occasional nutrient pulses rise from the bottom as **wind-driven upwelling**, never on a fixed schedule: a plume of deep water climbs from the floor (~1–1.5 min) and releases its nutrients along its path. Resuspended specks rising in it make it visible.
- **Temperature**, **salinity**, **oxygen**, **marine snow** (sinking detritus) and **runoff silt** are fields too, and the floor keeps a **deposit** per column (see the rules below). The column is shelf-sea scale (light reaches ~1% at the floor: tens of metres to ~150 m), so its layers are a surface mixed layer, a thermocline and a bottom mixed layer, never the open ocean's deep water.

### Cells (agents)
State: position, velocity, energy, age, phase θ (0–2π), genome, parent id.

### Genome — only perceivable genes
Every gene must change something you can **see or hear**. If it doesn't, it doesn't exist.

| gene | range | perceived as |
|---|---|---|
| `hue` | 0–7 | pigment shade within its form's family (colour by pigment, see Visual style) |
| `size` | 0.6–1.6 | cell size and chloroplast count; larger-looking cells (dinoflagellates are drawn big) sing up to 2.5 octaves lower and slower |
| `depthPref` | 0–1 | where it lives in the column, which sets its register |
| `omega` | 0.15–0.6 Hz | natural pulse/flash rate |
| `coupling` | 0–1 | how strongly it syncs with neighbours; length of its setae (spines) |
| `timbre` | 0–1 | the form and its instrument, continuously: soft cell ↔ armoured dinoflagellate (wood or plucked string) ↔ diatom glass (glockenspiel ↔ vibraphone); round coccoid cell ↔ glassy box-like frustule. Soft cells are, by lineage, green algae (felt piano ↔ pad), coccolithophores (celesta) or cryptophytes (kalimba) |

Mutation on division: small random walk (±8% of range) per gene, with a 5% chance of one larger jump. Daughters look and sound recognisably related to the parent.

## Rules (the whole engine)

1. **Drift**: Brownian motion + gentle movement toward the light level matching `depthPref` (phototaxis; the target is relative to surface light, so a cell holds its depth all day) + soft separation from close neighbours. Heavy drag. Everything moves slowly.
   - **Night descent**: in darkness cells follow the nutrient gradient down instead of seeking light; phototaxis pulls them back up at dawn (diel vertical migration). Diatoms don't swim: they only regulate their buoyancy, so they hold their depth at night (2026-10-22; before, the notebook's migration page showed them sinking ~10 m every night).
   - **Night rest** (circadian clock): as the sun goes down, upkeep and ageing slow to 12%, so cells survive the night without dividing.
2. **Metabolism**: `energy += light × nutrients × efficiency − maintenance`, per unit biomass, with size allometry: the nutrient term saturates as `N / (N + halfSat × size)` (small cells win in bright, nutrient-poor water) and maintenance scales as `size^-1/2` (large cells endure dim water). Uptake removes nutrients from the local field and stays bound in the cell until it dies.
   - **Succession** (author: "it's important to observe succession like in the real world; the more external factors at play, the more diverse the outcome"). Four approved local rules work together, measured with `sim-check`'s diversity and "leading the water" lines. Before them, worlds were one group (mostly centric diatoms) 82% of the time; with them (12 worlds x 6 h, see below) every group takes its turns.
   - **Silicate** (approved local rule, author: "it is important"): diatoms need silica for their glass. A silicate field diffuses, wells up from the deep and rises with upwelling plumes like nutrients; only glass cells take it, in proportion to how much glass they have (the timbre range where dinoflagellates fade into diatoms), at 0.6 per unit of nutrient, and their growth slows as it runs low (half-saturation 0.12). The silica stays in the frustule until the cell dies; then 30% dissolves where it dies and the rest sinks to the floor, so it returns far more slowly than nutrients. A diatom bloom strips the surface of silica and opens the water to green algae and dinoflagellates. Measured (8 worlds x 4 h): diatoms lead the water 35% of the time, green algae 64% (before: diatoms ~95%); alone it still left one group holding >= 90% about half the time, hence the rules below.
   - **Viruses** (approved local rule, kill the winner): host-specific, one per kind (the seven forms as the notebook counts them). Each tick the water records the biomass of every kind per grid node; a cell's risk of lysis per second is 0.007 · B²/(B² + 0.8²), B its own kind's biomass around it, so a crowded kind is hit hardest and rare kinds are nearly safe. A lysed cell bursts quietly (no cyst, no last note); 90% of its nutrients go straight back where it burst (the viral shunt), the rest sinks; its silica is released as usual.
   - **Dinophysis steals its chloroplasts** (approved local rule, kleptoplasty): a Dinophysis-form cell strikes a cell within reach (both radii + 2 units) at 0.15 per second, keeps 70% of its nutrients (the rest is excreted in place) and half its energy, and keeps one of its chloroplasts: the sprite paints its plastids in the colours of its last four prey. Stolen plastids fade (1/e in 240 s; a meal restores half); without them it photosynthesises at 15%, so it must keep hunting. Prey vanishes quietly. It meets the commonest prey most. More hunting backfires: at 0.2/s with eased grazing Dinophysis itself became the monopoly.
   - **Immigration** (approved local rule, "everything is everywhere, the environment selects"): the world still starts from 2 founder lineages (author: no need for more if newcomers arrive), and about once every 75 s a single cell of a new lineage drifts in from the open ocean at one side of the column, with random genes and form, at the depth it prefers, bringing its nutrients (counted as imported). Most vanish; when the water turns their way, their kind is already there. Before it a world could only ever hold its founders' forms (of 12 test worlds only 3 had any Dinophysis). Newcomers stop once a world is extinct (author: extinction stays an ending; before, they quietly brought extinct water back to life under its epitaph).
   - **Coccolithophores and cryptophytes** (author, approved forms): the soft-cell range splits by lineage (30% coccolithophores, 30% cryptophytes, the rest green algae), like the dinoflagellate forms, each with its own niche as a local trade-off. **Coccolithophores** grow at 80% of the top rate (calcifiers grow slowly) but take nutrients up twice as efficiently (half-saturation x 0.5), so they win in poor, calm water; their plates are a grazing shield (risk x 0.6) that costs upkeep (x 1.05) and is ballast (they sink a little). **Cryptophytes** catch dim light well (phycobilins: light felt as L(1 + 2.5)/(L + 2.5)) and are unarmoured (grazing risk x 1.3); Dinophysis takes a cryptophyte first when one is within reach (its plastids really come from them, via Mesodinium), so it turns pink-red. Without the slower growth, coccolithophores were strictly better green algae and took 60–97% of the water. Measured with them (12 worlds x 6 h): leading the water diatoms 15%, dinoflagellates 19%, green algae 17%, coccolithophores 40%, cryptophytes 9%; one group >= 90% 21% of the time; deaths grazed 50%, sardines 21%, lysed 18%, hunted 13%; no extinctions. Coccolithophores creep ahead in long calm runs (the poor-water specialists); cyanobacteria, next, compete for that niche, and the balance is to be revisited with them.
   - **Cyanobacteria** (approved local rule, author: "very important"): far too small and many to be agents, they live as two fields of biomass per grid node (about a cell's worth per unit, nutrient content 0.65 per unit, counted in the nutrient books): *Synechococcus*-type (pink-orange phycoerythrin, bright surface water) and *Prochlorococcus*-type (blue-green, a dim-light specialist). Each grows at 0.025/s x light x N/(N + 0.04) (the best uptake of all: they win in poor, calm water) toward 1.5 per node, respires (back to the water), is eaten by the grazers (who grow on it too, so a cyanobacterial bloom also feeds them) and is lysed by its own phages, hardest where dense. A trace always drifts in from the open ocean (counted as imported). Slow swirling currents (an eddy pattern that turns slowly, faster in wind) carry the fields, rescaled so nothing is made or lost. First settings let them take 70% of the water and halved the music; tuned, they bloom now and then. Measured with them (12 worlds x 6 h): leading the water diatoms 17%, dinoflagellates 6%, green algae 6%, coccolithophores 53%, cryptophytes 16%, cyanobacteria 3% (about 11% of the biomass); one group >= 90% only 4% of the time; music 3.1 onsets/s; no extinctions. Coccolithophores still lead too often in long calm runs: to rebalance with self-shading. **Retuned with the seasons** (2026-10-22, author: summer and early autumn should let them reign in calm, rich water): the shorter days had left them on the trace all year (lysis 0% of their losses, respiration 66-94%), so respiration 0.004 -> 0.0025 and grazers take them at 0.7 of the cells' rate. Quick check (3 game-hours): summer-born worlds 21-22 units vs 51-54 cells (was 5 vs 66); winter-born still on the trace. Not yet confirmed over whole years (author: no long run now).
   - **Synechococcus and Prochlorococcus trade off** (approved local rule, author, 2026-10-23): the two had been identical but for *Prochlorococcus*'s dim-light edge, so it was strictly better and *Synechococcus* (red) never bloomed, the reverse of a shelf sea. Now *Prochlorococcus* is the warm, poor-water specialist: it grows only from 15 °C (fully at 19 °C; Johnson et al. 2006: rare below ~15 °C) and takes nutrients up twice as well (half-saturation x 0.5), keeping its dim-light edge; *Synechococcus* grows 1.25x faster and tolerates cold. Swept (4 seeds x 3 game-hours from spring and summer): *Synechococcus* blooms alone in spring (peaks ~18), the two share warm summer water (~11 and ~14, about the old total), cells unchanged.
   - **Self-shading** (approved local rule): light below also fades by e^(-0.06 x living biomass above it in its column), cells and cyanobacteria (last tick's), so a dense surface bloom dims the water beneath it, limits its own depth and favours dim-light specialists below (cryptophytes, *Prochlorococcus*, elders). Phototaxis feels it too.
   - **Coccolithophores' own virus** is 2.5x fiercer (as EhV ends *Emiliania huxleyi* blooms in the real ocean): with it and self-shading the five cell groups share the water. Measured (12 worlds x 6 h): leading the water diatoms 17%, dinoflagellates 11%, green algae 23%, coccolithophores 27%, cryptophytes 19%, cyanobacteria 3%; one group >= 90% only 2% of the time (worst world 6%); music 2.8 onsets/s; no extinctions. The picocyanobacteria stay minor: the bloom-forming, buoyant cyanobacterium (with temperature, runoff and oxygen) is approved as the next step.
   - **Grazing eased** (author: too intense, other causes too rare): grazer rate 0.05 -> 0.035, sardines eat 60% of what they pass (was 80%).
   - Measured with all four (12 worlds x 6 h, the same test as the baseline): leading the water diatoms 13%, dinoflagellates 24%, green algae 64%; one group >= 90% only 9% of the time (worst world 22%; before: 82%); deaths: grazed 52%, sardines 19%, lysed 16%, hunted 8%, salps 1% (starvation and old age stay near 0: cells are eaten or lysed first, as in a productive water column); no extinctions, every world blooms and recovers.
   - **Turbulence (Margalef's mandala)** (approved local rule): small-scale turbulence inhibits dinoflagellate growth, diatoms don't mind it. Gain × `max(0, 1 − 1.5 · dinoWeight · stirring)`, the stirring the cell feels where it is (author-approved refinement, 2026-10-21): the wind's and the tide's, after stratification has damped them (the same coefficient the vertical mixing uses, without the overturning of water cooling at night), as a share of a full storm's at the surface. So dinoflagellates bloom in calm, stratified water and shelter below the thermocline when it blows, and the tide's stirring hinders them over the seabed at springs. (First built as wind × e^(−depth / 0.5 column), blind to the layers; dinoflagellates then led only 4% of the time.)
   - **Temperature** (approved local rule): sunlight warms the water where it is absorbed, mostly the top few rows; the surface row gives heat back to the air (15 °C; faster in wind, by evaporation); heat diffuses only weakly; cold shelf water (10 °C) slowly renews the bottom layer (the seabed itself takes no heat). Growth speeds up when warm: x Q10^((T − 18)/10), Q10 1.6 for cells, 2.2 for cyanobacteria; rotting x Q10 2. Warm water holds less oxygen.
   - **Vertical mixing** (approved local rules, author chose both): the wind stirs from the surface (fading with depth) and the tide from the seabed (fading upward over a tenth of the column), plus a weak background. **Stratification resists mixing** (after Pacanowski & Philander 1981): both are divided by (1 + 5 · the density step, light over dense, in degrees: warmth, and salt at 3.8 degrees per psu, judged over the rows around)² (judged over one row alone, mixing broke the water into stairs, the layering instability). Where dense lies over light (the surface cooling at night) the water **overturns** (convective adjustment). So the wind mixes a uniform surface layer that stops at a sharp thermocline and deepens in storms, the tide keeps a uniform **bottom mixed layer**, and calm water stratifies. Mixing carries heat, salt, oxygen and filamentous cyanobacteria, and half as strongly the nutrients and silica. Before these rules (the first build) the column cooled linearly from the mixed layer to the floor, with no thermocline and no bottom layer.
   - **Filamentous cyanobacteria** (*Trichodesmium*-like; approved local rule, author: "very important", named filamentous cyanobacteria by the author): a third cyanobacterial field, colonies of filaments ("sea sawdust"). They fix their own nitrogen (70% of their nutrient comes from the air, counted as imported: they fertilise poor water when they die), grow more slowly than the small cyanobacteria (0.024/s x light x warmth) and only in warm water (from 19 °C, fully at 23 °C), are hardly grazed (x 0.15, toxic) and are lysed by their own phages where dense. Gas vesicles lift them (1.2 units/s) and ballast built in bright light turns them down (v = rise x (1.4 L − 1)), so calm water gathers them into a **surface scum** that shades the water below (0.12 per unit) and burns in full sun; wind mixing stirs them down. Half of what dies is returned in place, the rest sinks as marine snow (scums collapse and sink).
   - **Storm runoff** (approved local rule): during a storm (wind > 0.55), now and then (at least 400 s apart) a lens of muddy fresh water spreads from the coast (one side, fixed by the seed) across the top 30 units, releasing 30 nutrients and silica (0.8 of that) on its way (counted as imported), with silt that shades the water below and settles out over ~150 s. It rains while the lens spreads. The lens is fresh (see salinity), so it floats and resists the wind.
   - **Tides** (approved local rule, author): the tidal current floods and ebbs twice a lunar day (12.42 h of 24, so ~2.6 min at 5-min days) and swings over the **spring-neap cycle**, springs at new and full moon (half a synodic month: ~74 min at 5-min days; the current is 1.4x its mean at springs, 0.6x at neaps). The tide's stirring follows the current squared (on average as before) and reaches higher off the seabed at springs. Where the current's stirring passes 1.5x its mean (springs) it lifts the floor deposit back into the water as marine snow (0.004 per s of the excess, through the stirred layer) and lifts resting cysts (0.004 per s of the excess, aloft for 30–120 s). So neaps let the bottom water stratify and run short of oxygen, and springs stir it, lift the floor and hinder dinoflagellates near it.
   - **Salinity** (approved local rule, author): a field in psu, shelf water 35. The runoff lens freshens the water it spreads through (down to ~32 at the surface); salt mixes and diffuses as heat does, shelf water renews the bottom layer, and the shelf's salt water slowly replaces the column from the sides (0.0008/s: the plume spreads away). Density follows a linear equation of state (one psu weighs as much as 3.8 °C of cooling: β/α = 7.6e-4 / 2e-4), so a runoff lens is a buoyant layer that resists the wind (a halocline) and can seal off the water below. No salinity tolerance rule: marine plankton cope with 30–35.
   - **Oxygen** (approved local rule): made where nutrients are taken up (photosynthesis) and used where they are returned (respiration, excretion, the viral shunt, rotting), at Redfield's 138 O2 per 16 N (0.27 of saturation per unit of nutrient, reading nutrient 1 as ~8 µM nitrate; it was one for one, which drove bloom water to 300% saturation), so it piles up in the lit layer and runs short where dead matter rots. The surface row breathes with the air toward saturation (1 at 15 °C, less when warm; faster in wind); shelf water renews the bottom layer slowly. With 1 = saturation (~5.8 mL/L), **hypoxia** is below 0.35 (2 mL/L, 2.8 mg/L: Diaz & Rosenberg 2008): cells there suffocate (up to 0.04/s at 0.08, severe hypoxia; a cyst may stay behind, as from a starving cell; HYPOXIA in the ledger), grazers die back and sardine schools steer away. Dead zones form in the bottom mixed layer under calm, stratified water after blooms, and storms or renewal end them.
   - **Marine snow and the floor deposit** (approved local rule): what sinks out (the lost share of dead, grazed, eaten and lysed cells, pellets) is no longer put straight on the floor: it falls as a detritus field (2.5 units/s), rotting on the way (0.004/s, using oxygen; without oxygen only a quarter of the rot goes on; faster when warm), and settles into a deposit per column that rots slowly (0.003/s) into the bottom water. The biological pump now takes minutes, and its rot is what empties the bottom water of oxygen.
   - Measured with all of them (12 worlds x 6 h, 2026-10-21): leading the water diatoms 22%, dinoflagellates 3%, green algae 13%, coccolithophores 24%, cryptophytes 13%, cyanobacteria 8%, filamentous cyanobacteria 17%; one group >= 90% 0% of the time (worst world 1%); every world blooms and recovers; surface 17–23.5 °C, bottom water 11–13 °C, a mixed layer, thermocline and bottom mixed layer in stratified water; filamentous blooms peak ~100 with a scum in 9 of 12 worlds (~4% of the time); bottom oxygen ~0.6, dipping to 0.02–0.2 near the floor in brief dead zones (~1% of the time; no cell has died of hypoxia yet; superseded, see below); runoff ~3/h; music 2.6 onsets/s, 29% near-silence; deaths grazed 66%, lysed 16%, sardines 13%, hunted 4%. Extinctions: 0 in this run; 1 in the first run of this step and 3 in a run with slower bottom renewal (0.003, oxygen 0.75; the three were the worlds with the biggest filamentous blooms and most dead-zone time), against ~1 per 57 lived hours before. Bottom renewal brackets dead-zone frequency: 0.002 gave hypoxia ~50% of the time, 0.004 ~1%.
   - **Balance settled with the author (2026-10-21)**, against written targets: dinoflagellates lead >= 8% of the time; dead zones 3–15% of the time, brief and episodic; a cyst bank of ~10–40; every group leads >= 3%; one group >= 90% <= 5%; music 2.5–3.5 onsets/s; extinction watched, not targeted (author: not too worried about it). Parallel one-parameter sweeps (12 worlds x 2–3 h each) chose: the mandala on local stirring (dinoflagellates 4% -> 13–29%), bottom renewal 0.004 -> 0.0022 (with tides the dead-zone frequency follows renewal smoothly: 0.0025 ~5%, 0.002 ~13%, where without tides it jumped from ~1% to ~50%), encystment thresholds 0.75/0.55, dormancy 30–60 min (6–12 game days), floor germination 1/3600 s. Before them (24 worlds x 6 h): dinoflagellates led 4%, hypoxia 0%, the cyst bank 0.
   - Measured with them (24 worlds x 6 h, 2026-10-22): leading the water diatoms 26%, dinoflagellates 23%, green algae 7%, coccolithophores 16%, cryptophytes 8%, cyanobacteria 7%, filamentous cyanobacteria 15%; one group >= 90% 0% of the time (worst world 3%); bottom water hypoxic 11% of the time (median world 12%, worst 33%: the world with the longest filamentous scum), 35 cells died of hypoxia in 144 h; cysts: ~16 made and ~13 germinated per hour, a bank of ~16; music 2.6 onsets/s; no extinctions. Over 12 h (11 worlds) hypoxia is 14% of the time and 16% in the second half, the floor deposit levelling off near 110: the bottom water settles rather than sliding into a permanent dead zone (if kept worlds feel too dead-zoned, renewal 0.0023 is the next step). Groups still take turns within a world: in 12 h runs a group can be absent for hours (cryptophytes led 0% in 4 of 11 worlds) and returns.
   - Speed: the new fields cost about 25% in thin water (less with many cells); the snapshot grew to ~150–240 KB.
3. **Division**: when energy passes a threshold, split into two daughters with mutated genomes and half the energy (and bound nutrients) each. The mother continues as one daughter (keeps her id, age resets); the other daughter's parent is her. A hard cell cap only blocks division, as a backstop.
4. **Death**: energy below zero, age past lifespan or hypoxia → the cell fades out, sounds one soft last note, and returns its nutrients: part recycled where it died, the rest sinking as marine snow (the biological pump).
   - **Extinction is an ending** (author's decision): rare when only watching, a matter of hours and bad luck (never ageing, never scripted); in phase 6 the player can also cause it by mismanaging the water. When the last cell and the last cyst are gone the water goes on, empty and silent, and the HUD keeps an epitaph: seed, how long the world lived, EXTINCT. In the kept world a tiny TAP TO SEED NEW WATER follows once the epitaph has appeared and starts fresh water with a new seed. A living world can be ended only from the notebook's ledger page (NEW WATER, then YES; author, replacing the earlier "only the biology ends it"). A scratch world starts again on reload. Grazers starve away slowly after a die-off (decay 0.0025/s), so crashes run deep (measured 2026-10-21, 16 seeds x 12 h: 3 extinct (h 2.2, 4.6, 8.8), about one extinction per 57 lived hours, so a kept world lives about 5 days on average; author: right for now): worlds often fall to a handful of cells and recover, and now and then one does not.
   - **Resting cysts** (encystment, approved local rule, replacing cysts left by dying cells, which grazing and viruses had made almost impossible: ~0.3 a hour and a bank of 0): the forms that make resting stages (green algae's resting zygotes, *Alexandrium* dinocysts, centric diatoms' resting spores; not coccolithophores, cryptophytes, *Dinophysis*, *Prorocentrum*, pennates, or marine *Tripos*, which hardly encysts; its freshwater cousin *Ceratium* does) turn into a cyst while alive when nutrients (for diatoms also silica) have run short for a while: their sufficiency N/(N + halfSat), smoothed over 60 s, below 0.75, up to 0.001 per s at 0.55. The cell leaves quietly; the cyst keeps all its nutrients and silica and sinks to the floor. After 30–60 min of dormancy it germinates only in oxygenated water (anoxia keeps cysts dormant, so cyst beds outlast dead zones) with nutrients: slowly on the floor (1/3600 per s), within a minute when a spring tide has lifted it into the water. It dies after 2 h. So cysts form at bloom ends, as real ones do, and a bloom's lineages come back from the bed after the water recovers. The seed bank against extinction.
5. **Grazing pressure and visitors**: density-dependent mortality from an invisible grazer field Z on the nutrient grid. Grazers eat local biomass B with a type III response `f = B²/(B²+K²)` (sparse cells find refuge), grow on it and starve slowly (`dZ/dt = Z(growth·f − decay)` + slow diffusion, never below a floor). Per-cell mortality is `rate·Z·K·B/(B²+K²)`, divided by `1 + refuge·(chain length − 1)` for chained cells (a size refuge). The lag between food and grazers is what ends blooms and lets the water recover. Grazed cells vanish quietly (no cyst, no last note); 70% of their nutrients are excreted in place and the rest sinks as fecal pellets. The grazers are drawn as krill where the field is dense (the field made visible, nothing more): giants beside the cells, so only a sparse share of the swarm is drawn, each detailed (translucent pink-orange body, segmented abdomen and tail fan, big black eyes, long waving feelers, a green gut from eating diatoms, a feeding-leg basket, swimmerets beating in a travelling wave, small blue photophores, no glow), gliding in loose swarms and flicking the tail when they dart; no voice of their own. Each krill is shaded its own way: a rose or amber body, some a tone darker; length 6.5. The field behaves like the real grazers (single-celled grazers and copepods eat most of what phytoplankton grow; Calbet & Landry 2004), so **copepods** are drawn with the krill, more numerous (author, 2026-10-22): small translucent teardrops with an orange oil drop, a red eye, long antennae spread at rest and swept back as they hop, and a forked tail; they hang, sink and hop. At 1× they are pale specks. They are drawn about 4.5 units long (krill 7.5: author, 2026-10-23, krill bigger than copepods, and copepods fewer so they never crowd the screen: at most 2 per grid node, 0.25 of its presence each), still bigger than a typical cell, since a real copepod is ~20 Dinophysis long (author: they had looked smaller than Dinophysis); true scale is impossible beside cells drawn large.
   - **Visitors** (approved local rule): filter feeders find plankton-rich water. Arrival chance rises with living biomass, so blooms draw them in; never on a timer. A **sardine school** (big, detailed fish: blue-green backs, spot row, silver flanks whose scales twinkle, beating forked tails; the whole school flashes silver when it wheels round) sweeps across, leaning toward richer water, and swallows cells in its path; a rich pass makes it wheel round for another (up to 3), so it can take half a bloom. A **salp chain** drifts slowly, filtering a modest share, its fecal pellets sinking fast. An **ocean sunfish** (brown-grey back, mottled silver flanks, white belly, tall curved dorsal and anal fins flapping together, scalloped clavus, a small round mouth that gapes open and shut as it sucks in prey) comes for the salps and bites them off one by one; it never eats cells. It keeps to one prey until it has bitten it off and comes at it from the side it is on (2026-10-23: aiming its mouth from whichever way it faced once made it twist left and right). When it is done it rises to bask just under the surface and drifts away. What visitors eat is partly excreted in place, partly sinks as pellets, and partly leaves the column with them.
   - **Jellyfish and comb jellies** (approved local rule, author, 2026-10-22): they eat zooplankton, so they come where the grazer field is rich in the upper water, when the surface is warm (from ~18.5 °C) and the sea is calm, as real jelly blooms do; never on a timer (~1.5–5 groups per hour each). A group of 3–6 **moon jellies** or 4–8 **comb jellies** drifts slowly across. Each eats the grazers around it (5%/s and 4%/s of the field within reach), which frees the phytoplankton beneath: a trophic cascade. Their tentacles startle cells, and glowing dinoflagellates flash as they brush past. The **sunfish** now comes for jellies as well as salps and bites them off. Redrawn with the author (2026-10-23: the rings looked like circles, the jellies too simple, symmetric and rigid): each is shaped its own way and feels squishy, leaning with its drift and a slow sway of its own, its tentacles and arms streaming behind and lagging. Moon jellies: a translucent bell (the water seen a shade brighter through it, a lit rim and sheen, faint radial canals), lopsided, its crown off-centre and its margin rippling; four pink or violet horseshoe gonads as soft crescents around its centre (the near two clearer); a fringe of fine tentacles of uneven length; four frilly oral arms of their own lengths; the bell squeezes narrow and tall on each pulse (every 1.6–2.6 s), one side a moment before the other, and relaxes wide. Comb jellies: a clear egg leaning mouth-first, breathing a little, with a statocyst, a faint gut and tentacle pockets; eight comb rows (the near ones seen as it slowly rolls) run with travelling rainbow waves (diffraction, not bioluminescence), and two long branched tentacles stream behind. **Voices** (author: "very angelical, like a strumming harp, with a reverb shimmer tail"): each moon-jelly pulse strums a harp arpeggio up the water's scale around C4 (plucked triangle strings with an octave partial, a lowpass closing as they ring, an octave-up shimmer swelling into the reverb only); comb jellies play sparse, high harp harmonics. At most one strum every 0.9 s (moon) / 2.6 s (comb), through the music bus. In the ledger as JELLYFISH and COMB JELLIES.
6. **Phase coupling (Kuramoto)**: `dθ/dt = 2π·omega + coupling·K·mean(sin(θj − θi))` over neighbours within radius R. When θ wraps past 2π, the cell **flashes** (bioluminescence) and may sing. Synchronised clusters — colonies — emerge from this rule with no colony code. The sum uses the phases from the start of the tick (order-independent) and the arithmetic sine `dsin` (deterministic).
7. **Pitch attraction**: each cell holds a scale degree. When it flashes, it nudges its degree toward a consonant interval (unison, 3rd, 4th, 5th, octave) with the degrees its neighbours sang recently. Chords emerge from proximity and sync.
   - As built: the degree is inherited (a daughter starts one step away 25% of the time); on each flash the cell moves at most one step (down, stay, up) to the degree that scores best against neighbours within 12 units that flashed in the last 4 s (consonance by interval class: 4th/5th > 3rds/6ths > unison/octave > 2nds > tritone, semitone; a small bonus for staying). All moves in a tick are applied after everyone has listened (order-independent). Runs on the music's own seeded stream, so the music never changes the biology. **Choir**: against a neighbour flashing in phase, or a chain mate, a unison only doubles the note and scores nothing, so colony mates spread onto fifths and thirds; chain mates always join each other's phrase and the first note of a phrase rings full length, so a colony flashing together is heard as a chord. Within a phrase, a motif note that would form a semitone or tritone with a note still sounding anywhere in the water bends one scale step (the first note stays).
   - **Lineage motifs** (approved local rule): each lineage carries a short tune, 3–5 scale steps from the cell's degree (mostly steps, some leaps and repeats), on a Euclidean rhythm (notes spread evenly, rotated) over a loop of 3–8 slots spanning one period of the cell's own pulse, so every lineage loops at its own length and tempo and the loops drift against each other. Inherited at division; 12% of the time a note moves a step, 3% a note is added or dropped (repeat with controlled variation). A cell that starts singing keeps singing for a bout of 1–3 flashes, so its tune returns, transposed as rule 7 moves its degree.

That's it. Colonies, blooms, silence and rhythm must all come out of these rules.

## Harmony: the water chemistry

- One shared **harmonic field**: a root and a scale (pentatonic family: major, dorian, minor, hirajoshi). Every note is quantised to it. **Only one tonal centre at a time.**
- The root changes rarely — a major event, minutes apart. It is driven by the population (elders, phase 5) and later pulled by the player. Never on a timer.
- **Register = depth.** Top of the column sings higher octaves, bottom sings lower. Diel migration therefore produces a slow registral arc for free.
- As built: the **root is chosen by the seed** and stays until elders move it (phase 5). **The scale follows the season, as a probability** (author, 2026-10-22): a world is born in a mode drawn from its season's weights, and each key change draws again from the weights of the season it happens in (winter mostly hirajoshi, spring major, summer dorian, autumn minor; every mode stays possible), on the music's own stream. Register spans four octaves, C6 at the surface to C2 at the floor, but **not evenly** (author, 2026-10-22: most cells live in the lit upper water, so even octaves made the music top-heavy: C5 49%, C4 36%, C3 10%, C2 3%): the pitch follows depth through knots (C5 at 16% of the column, C4 at 24%, C3 at 48%), fitted from recorded notes to the author's shares (C5 and C4 at most 30%, C3 ~20%, more C2), and the biggest-looking cells sing up to 2.5 octaves lower. Measured (8 worlds x 40 min, all seasons): C2 14%, C3 23%, C4 30%, C5 29%, C6 4%. The note is the cell's scale degree in the octave nearest its target.

## Audio

### Absolute rules (never break)
- Never use `cancelScheduledValues`.
- Never ramp to exactly 0. Exponential ramps go to `0.0001`.
- Set `osc.frequency.value` before `osc.start()`.
- Only discrete, enveloped note events. No oscillator runs forever.
- Build the reverb impulse response once at init. Never allocate AudioBuffers during playback.
- Disconnect every node after its envelope ends.

### Voice budget (the most important musical constraint)
- At most **16 simultaneous** ecosystem voices and **~6 note onsets per second** overall (tunable; raised from 10 and 2.5 with the author when motifs arrived).
- When a flash wants to sing and the budget is full, it only flashes visually. Cells in larger synchronised clusters get priority, so colonies are heard over loners.
- Silence is allowed and expected. If the population thins, the music thins.
- As built, the budget is decided in the simulation (sim time, deterministic, so `tools/sim-check.mjs` measures the music): a token bucket (6/s, burst 14) and 16 voices. **Singing urge** (local rule): a flash rarely starts a phrase on its own (4% when the cell is growing well, by its recorded light × nutrient conditions; a floor of 15% of that when resting at night or growing poorly; glowing dinoflagellates sing in the dark; starving cells, energy < 0.25, are silent). A cell flashing within 0.5 s after a neighbour began a phrase joins in with its own (85%), so synchronised colonies sing together (kin motifs in counterpoint) and loners sing alone. A phrase needs a token per note (a loner twice that); each note sounds only if a voice is free. Dying (not eaten) cells sound one soft last note if a voice and a token are free. Measured: ~3 onsets/s median, the cap in blooms, ~20% of the time in near-silence (thin water, nights).
- Time-lapse thins the music: at 2×–8× only a share 1/speed of the phrases plays (whole phrases); the simulation is unchanged.
- Browsers need a gesture before sound: a tiny pixel-font TAP TO LISTEN sits in the water until the first tap/click/key. A small beamed-note glyph beside the notebook glyph (shows with the HUD), or `M`, turns the **music** off and on (author; MUSIC OFF in the HUD): the cells' notes, drones and plucks fade out, while the ambience, bubbles, krill clicks and the school's whoosh go on.

### Ecosystem voice
- The voice follows the form, as the sprite does (author's decision), blended continuously by `timbre`, as real instruments built from partials that each fade at their own rate (higher partials first): soft flagellates are a **felt piano** (small) melting into a **breathing pad** (big, or steadied by an elder: a detuned twin and a slow vibrato); dinoflagellates are **wood** (marimba: *Alexandrium*, *Prorocentrum*) or a **plucked string** (*Dinophysis*, *Tripos*), by lineage form; diatom glass is a **glockenspiel** (small) or a **vibraphone** with its slow tremolo (big); coccolithophores are a **celesta** (small bright bells: a struck partial set with a quick inharmonic shimmer) and cryptophytes a **kalimba** (a plucked tine: a strong fundamental and a quick high tink), each with its own short attack and ring. Cyanobacteria are heard as a **shimmer** (author): faint grains, tiny high notes from the scale (around C7, now and then an octave up), at up to 7 per second as more of a bloom is on screen, panned toward it. Within a family the size gene picks the instrument, tilted toward the mellow one. A lowpass follows each note (bright at the strike, darker through the fade). Measured mix: glockenspiel ~38%, vibraphone ~28%, piano ~11%, pad ~8%, wood ~8%, string ~7%.
- **The world as macros** (audio only): brightness follows daylight, the delay's echoes follow the sea state (long in glassy calm, broken up in wind), the reverb follows bloom density, and visitors in the water cast an audible shadow (the sound dulls while a school, sunfish or salp chain passes). Eased, never scripted.
- **Visitors' voices** (author, replacing "visitors have no voice of their own"): a **sardine school** on screen holds a soft, airy chord in the water's key (root, fifth and ninth from the scale, around C4, each a slightly detuned pair for shimmer), built from overlapping 10 s swells every 4.5 s, so it breathes while the school stays and fades after it leaves. The **sunfish** calls every 12–20 s while on screen: a slow, warm low note (a filtered saw over a sine, around C3) gliding up a fifth; basking at the surface it calls softer and an octave higher. Both go through the music bus, so the music button silences them; they follow the key as it modulates.
- **Sound halos** (author, 2026-10-22): when a visitor sounds (the school's chord, a salp barrel's note, the sunfish's call, a jelly's strum) one ring of its colour spreads from where the sound came from and fades over ~1.6 s (sardines light blue, salps emerald, sunfish gold, moon jellies their gonads' rose or violet, comb jellies rainbow). A **crowd of sardines**: the school's chord comes again from other fish as short panned echoes, and its whoosh has a few followers a beat behind. **Jellies strum now and then**, not on every pulse (30% of pulses, after a random 1.4–7 s rest; comb jellies 25%, 3–9 s), and a strum drops an octave or two at random. Harp strings are one oscillator each, with the shimmer on the top string only: whole strums of three oscillators per string overloaded phones and crackled.
- **The top of the mix** (author: high notes and shimmers were harsh): a gentle high shelf (−6 dB above 4.5 kHz) on the whole mix; the limiter has a soft knee and a 5 ms attack (its hard 2 ms one crackled on the low drones).
- **Predators are heard** (author-approved): beyond their own voices, cells brushed by a passing sardine school, salp chain or sunfish flash and blurt a short, high staccato note an octave up (startle; one per cell per 3 s, from the same budget), so a school sweeps through a flurry of plucks. Where the grazer field is dense, notes are duller and shorter (muffled), so heavy grazing sounds smothered before the die-off. The eaten simply stop singing, so a feast leaves an audible hole.
- **Melody over chord, chains arpeggiate** (author-approved): in a free colony the cell that starts sings its tune and neighbours who join hold one long chord tone each (release × 1.6). A chain plays its chord as an arpeggio instead: its cells' notes from low to high (and back down for a straight chain; round and round for rings and stars), 4–8 notes over one period of the pulse, once per chain until it has rested.
- **Richer voices**: soft pads breathe (their filter opens through the swell and closes through the fade); pads steadied by an elder add a late shimmer an octave up; every note varies slightly in loudness, brightness (louder is brighter) and timing; drones evolve (a slowly beating second sub, a partial two octaves up blooming late); the delay time drifts with the water's motion like tape flutter.
- **Salp voice** (author: "gentle, smooth sequenced melody"): while a salp chain is on screen it plays a soft legato line, one step per barrel along the chain (0.62 s apart, then two steps of rest before it loops), each barrel's note a scale step from the last (a walk fixed by the chain, around C5), a sine with a faint octave twin under a gentle lowpass, panned to the barrel. A barrel the sunfish bites off leaves a hole in the tune. Through the music bus.
- **Filamentous cyanobacteria** join the cyanobacteria's shimmer lower and slower: warmer grains around C5 (up to 3/s with the colonies on screen). **Rain** (while runoff spreads) is heard from under the water as bubble chirps, as real rain is.
- **Krill** are drawn mostly where they are eating (hungry swarms vanish within ~2–3 s and need dense food to stay, author: they should leave quickly; so the water clears after a die-off while the grazing pressure lingers) and are heard as a faint crackle of tiny clicks in short trains, denser with the visible swarm but saturating.
- **Ambience** (author-approved): the ocean itself, from filtered noise and short tones, every sound a discrete swell-and-fade event (overlapping, so the bed never stops), all following the world: the surface wash (soft and slow in calm water, loud, bright and quick in wind), a deep hum (darker at night), a groan while an upwelling plume rises, a whoosh as a sardine school sweeps by, and a chirp for some of the visible bubbles (author, 2026-10-23: they were too constant; 45% chirp, at most 3 a second; gas seeps always). **Bubbles** (render): breaking chop entrains clusters just under the surface that sink a little and rise back to pop; now and then gas seeps from the sediment and a few bubbles rise through the whole column.
- **Singing is seen**: a singing cell swells (a dot becomes a speck at 1×) and brightens with its note's envelope, and one ring of its pigment spreads from it, timed to the audio, at every zoom.
- Stereo pan from x position. Deeper cells are quieter and wetter.
- Shared chain: `voices → ecosystemBus → lowpass → (dry + reverb send + subtle delay send) → master → compressor → output gain → peak limiter → out` (loudened for phone speakers; the limiter holds the peaks. 2026-10-22: output raised a tad (1.65) and the compressor eased to -22 dB, 3:1, 0.5 s release; author: it needs dynamics to breathe).
- The ecosystem is the room the music happens in: dark, wet, soft. Never harsh, never bright fizz.

### The hand in the water (phase 6, redesigned with the author)
No keyboard, no MIDI, no voice of the player's own: the water is the instrument. The author found the original mother-voice player too complicated and off-goal.
- **Tap to scatter**: cells near a tap swim away for a few seconds (an escape response, as real dinoflagellates flee a disturbance), flash and blurt startle notes. Taps work at every zoom. A ripple of light (three rings, render only) spreads from the tap out to the reach of the scatter and fades over ~2 s.
- **Swipe to strum** (at 1× zoom, where dragging can't pan; a mouse drag on desktop): every cell the finger passes through plucks its own note in its own voice and register, so moving up through the water plays low to high and down plays high to low, like strumming a harp. Plucks bypass the voice budget (with a safety cap), ring and flash. The finger also drags the water a little along its path, and leaves a fading pixel wake.
- **Toward the light opens, toward the deep closes** (author): while strumming, moving toward the surface opens (brightens) the master filter and moving toward the deep closes (darkens) it, so an upward strum rises in pitch and into the light together.
- **Sideways makes the filter ring** (author, replacing an earlier sideways octave that was too subtle to hear): sideways travel builds a resonant peak (a peaking filter after the master lowpass, Q 5, up to +12 dB) whose frequency follows the finger across the water, 220 Hz at the left edge to 3.5 kHz at the right, so a sideways strum sweeps a vowel through everything playing. When the finger lifts the peak fades and the filter settles back over ~2 s.
- Player input enters the simulation at tick boundaries; a touched world no longer matches its seed (the seed is the starting point, not a recording).

## Visual style: pixel art

References: the "bit_wonder" style on Instagram — dark backgrounds, chunky clumped sprites with 3-tone shading, dithered gradients and caustics (top-down koi pond, pixel sunsets), tiny pixel-font HUD numbers.

- **Low internal resolution**: render everything to an offscreen canvas of 180 × 320 px, then upscale by an integer factor (tolerating 1–2 px of overhang from fractional device pixel ratios). `imageSmoothingEnabled = false`, CSS `image-rendering: pixelated`. Centre with letterboxing.
- **Camera (render only)**: pinch / mouse wheel to zoom between snapped levels 1×–8× (1× shows the whole column), drag to pan. Pixels never get bigger: sprites and backgrounds are re-rasterised at each zoom, so detail appears as you zoom in. Dither is anchored to the world so it doesn't crawl while panning.
- **Fixed palette** of 72 colours defined in `Palette`: water ramp, light and accents, ten pigment ramps of five hue-shifted tones (gold, green, rose, violet, emerald, light blue, blue, and the earth tones brown, amber, olive), greener "bloom water" twins of the water ramp, and "milky water" twins (chalky turquoise, where coccolithophores bloom and their shed plates linger; their own colours at every hour).
- **Colour by pigment** (author): each form shows its own pigments' family and the `hue` gene picks the shade within it, so mutations shift a lineage to a neighbouring shade of the same family: green algae green ↔ emerald (chlorophyll b); coccolithophores yellow ↔ olive ↔ green (author's choice) under white plates; cryptophytes rose ↔ violet ↔ blue ↔ light blue (phycoerythrin to phycocyanin); *Alexandrium* brown ↔ amber ↔ rose, *Tripos* brown ↔ amber ↔ gold, *Prorocentrum* amber ↔ gold ↔ brown (peridinin); *Dinophysis* a pale rose cell patched with its prey's colours; diatoms the widest family (author: diatoms are diverse), light blue ↔ emerald ↔ green ↔ olive ↔ gold ↔ amber ↔ brown. Every pixel is a palette colour. No alpha blending, no blur, no canvas gradients.
- **Gradients and glows via ordered dithering** (4×4 Bayer): flat colour bands with dithered seams only near the band edges. Light is applied with a palette "light-up" table (each colour's next brighter step), so shafts, caustics and flash glows stay on the palette.
- **Background**: deep navy/teal water column, banded from lighter at the top to near-black at the bottom; an undulating surface seen from below with specular glints that twinkle where the wave slope catches the sun; god rays (thin beams focused by the moving surface, fanning from a virtual sun and leaning with it through the day, bent by a refraction shimmer near the surface); a slow cellular caustic network near the surface; a seafloor of sediment, microbial mat and pebbles; marine snow in three parallax layers (far specks, mid snow, near out-of-focus flocs). Water tints greener where cell biomass is dense, so blooms are visible as colour.
- **Cells look like phytoplankton, not blobs.** Procedural sprites generated from the genome, as if seen under a microscope: a translucent cell body with a lit rim (upper-left) and a selective dark edge (lower-right), and chloroplasts inside, each shaded on its own (highlight upper-left, shadow lower-right).
  - Form follows the genes continuously, never via cell types: `timbre` turns a round coccoid cell into a glassy box-like frustule with a girdle seam; `coupling` grows setae on cells large enough on screen (polar spines on elongated cells, corner setae on squat box-like ones, radial spines on round ones); `size` sets cell size and the number of chloroplasts (one cup in small cells, several discs in large ones); `hue` sets the pigment ramp. Soft, low-`timbre` cells carry flagella that beat with the cell's phase θ.
  - A per-lineage sprite seed fixes elongation (squat to pennate-like) and the chloroplast layout, so daughters look recognisably related.
  - Body radius 1.25–4 world units in the simulation; cells are drawn at half of it (dinoflagellates 1.6× larger), so at 1× they are fine 1-px dots and 2×2 specks beside big fish, and the 6× and 8× zoom levels reveal the detailed cell. Cells tumble slowly. Cache the sprite per cell, zoom level and rotation step, with a 2–3 frame wobble (membrane swell, chloroplast drift); rebuilds are rationed per frame (at least 3 a frame; a sprite built for another zoom is never drawn, the cell is a speck until rebuilt: on a slow phone a watched cell once stayed at 8× size after zooming out).
  - **Mixed chloroplasts**: a cell whose `hue` sits near the next colour on the wheel carries some chloroplasts of that colour (as in kleptoplastic dinoflagellates).
  - **Dinoflagellates** in the middle of the `timbre` range (between soft cells and diatom glass): drawn 1.6× larger than their size gene alone (they are the big cells; not *Tripos*, whose horns already make it big: author, 2026-10-23, it got too big), whirling as they swim; armoured thecae with a slightly spiralled cingulum groove holding the transverse flagellum, a sulcus, and a trailing flagellum. The lineage picks the form: *Alexandrium* (round, thecal plate seams), *Dinophysis* (laterally flattened, open funnel collar and sail-like sulcal list), *Tripos* (three long curved horns) or *Prorocentrum* (egg-shaped valves with a suture and an apical tooth).
  - **Coccolithophores**: a round cell (no spines, no flagella drawn) under oval chalk coccoliths spread over a sphere that turn with the cell, each with a raised white rim (lit on the upper left), blue-white radial spokes and a pale centre, the far side first; the pigment cell peeks between them. Cells too small on screen for plates show chalk flecks. Where they bloom the water turns milky (smoothed over 40 s: shed plates linger).
  - **Cryptophytes**: a slipper (1.7 long, the belly flatter, narrowing toward the back), a furrow near the front, one big chloroplast along the back, two unequal flagella from the furrow end.
  - **Cyanobacteria**: single-pixel specks where they are dense (pink-orange and blue-green, bright or highlight), denser water showing far more than thin, twinkling slowly; a streaky texture drifting with the current (render only) breaks a bloom into drifting filaments and patches. From 2× zoom the dense patches also hold **conglomerates** (author, 2026-10-23: more vivid close up, still plume-like): little colonies of 3–7 round shaded cells on a lattice that drifts with the texture and sways. Thin water shows nothing.
  - **Diatoms, the jewels**: towards the top of the `timbre` range the soft outline becomes glass geometry chosen by the lineage — a round, triangular, square, pentagonal or hexagonal valve seen face-on, or a pointed pennate boat when elongated — with radial striae or areolae lattices, a raphe on pennates, horns at polygon corners, and iridescent rims that shimmer through the bright ends of every pigment ramp as the cell turns (frustules are real photonic crystals).
  - Light shafts and caustics brighten cells passing through them; deep cells are muted.
- **Seafloor scavengers (decoration)**: amphipods, ostracods and isopods walk in where detritus has recently fallen, pick at it, and walk off out of frame. Driven by the simulation's record of exported detritus per column, so they come after die-offs; they never touch the simulation. Zoomed out they are simple shaded shapes; from 3× they show anatomy: amphipods with overlapping body plates, an amber gut, a kidney eye, beaded antennae, a gnathopod claw, jointed legs (front ones forward, back ones back), beating pleopods and uropods; isopods with flattened plates, a tail shield and forked uropods; ostracods with a bean-shaped pitted shell, a naupliar eye, legs at the gape and bristle-fanned antennae. Feeding ones dip their heads to pick at the detritus.
- **Filamentous cyanobacteria**: golden-brown colonies (straw to gold) on a lattice drifting with the current: tufts (fine filaments lying loosely side by side, splaying toward the ends, waving, broken into short trichome pieces close up) or puffs (filaments radiating from a centre); each sways, bobs and turns slowly (author: looser, not solid). At 1× they are sawdust specks. The **scum**: a patchy golden-brown mat just under the surface where the surface row is dense (author: fine as is).
- **Marine snow, the floor deposit, mud and dead water**: flocs fall where the detritus field is (single grey-brown specks at 1×, loose clumps from 2×); the deposit lies as olive-brown fluff on the sediment, thicker where more has settled, and the crawlers pick it over (render only: it settles back over 2 min); white sulphur-bacteria mats (*Beggiatoa*-like) patch it where the bottom water is near anoxic. Runoff tints the water tea-brown where silt is; hypoxic water dithers to murky olive-black; an anoxic floor seeps gas more often. Rain while runoff spreads: rings on the surface seen from below, some leaving a bubble.
- **Bioluminescent dinoflagellates** (author-approved): an inherited trait of *Alexandrium*-form cells only (gained 3% / lost 15% per division, so glowing clades are rare and come and go; cysts keep it). At night they flash blue-green with a wider dithered halo, on their own phase flash and when disturbed (a sardine school, salp or sunfish brushing past, breaking chop near the surface). The one exception to the one-step flash rule below; still palette colours.
- **Flash**: a soft swell and fade (about 1.5 s), never more than one palette step brighter; a faint dithered halo spills onto the water and nearby cells, and cells very large on screen add faint broken arcs. Calm, never electric.
- **Lineage threads**: 1-px dotted line from a young cell to its living parent, only while the two are still close (a few cell widths), fading with the child's age and with distance; never long lines across the water.
- **Liveliness without speed**: the water (surface, rays, caustics, shimmer, snow) animates on its own clock, livelier than the ecosystem and hurried or slowed by the wind, and every cell moves on its own clock at its own tempo, 1× to 8× real time, so cells at different tempos share the water: at high tempo a cell darts around its simulated position on a wandering leash, spirals and tumbles faster. The species sets the top speed (small, quick-pulsing cells reach 8×; large slow ones ~3–4×; diatoms don't swim and only rock); activity sets how much of it is used. How lively a cell swims shows how it is doing: flagellates follow their recorded growth conditions (light × nutrients) and sleep at night; dinoflagellates are the night swimmers, active in the dark while they have energy. Render only: the ecosystem keeps its slow pace.
- **Rays are occasional**: they need the sun up, some chop on the surface (a glassy surface focuses nothing; rough water shatters them into flickers) and clear water (murky bloom water hides them). They come and go with weather and blooms.
- **Time-lapse**: `?speed=2|4|8` or the `[` / `]` keys run more of the same fixed ticks per second (still deterministic). No on-screen control.
- **HUD (minimal, diegetic)**: a microscope readout in a tiny built-in 3×5 pixel font drawn in code: seed, time, population, magnification (and time-lapse speed when above 1×). Small, in a corner, fades after inactivity. No panels, menus or knobs anywhere.

## Curiosities (author, 2026-10-22)
Now and then (first after 30 s, then every 50–100 real s (author, 2026-10-23: too rare when zoomed out); zooming in to 3× or more brings one about the cells in frame after 10 s, once until the camera zooms out (author, 2026-10-22: it had seemed never to appear when zoomed in); never with the notebook open or while catching up) a small **"i" in an air bubble** rises and sways in a corner. Ignored, it fades after 25 s. Tapped, it pops with a bubble chirp and opens a card in day colours: the topic, with the form's icon for a species, the fact, and its source. Any tap closes the card. Render and input only: it never touches the world.
- **The fact follows what is in view:**
  - zoomed in (3× or more): the forms in frame, weighted by their numbers (a lone cell counts less);
  - the cyanobacteria or filamentous colonies on screen;
  - any visitor on screen; krill and copepods (grazers);
  - the seabed when the camera looks at the bottom, the surface when it looks at the top;
  - zoomed out: the ocean, the water column and nutrients;
  - and the water's state: a dead zone, milky water, a scum, night and glow, storms, tides, upwelling, runoff, a bloom or a crash.
- Facts already read are skipped until a topic runs out (remembered in this browser only).
- **Why facts** (author, 2026-10-22: "the user doesn't know much of the ecology... the info is important to contextualize and give meaning to what the user sees happening in real time"): facts marked `why` explain the ecology behind what is seen (why a form thrives in this season or water, why it lives at its depth, what an adaptation buys it, why a bloom, a crash, a scum or a dead zone happens). Those with a `when` (all must hold: the season, `mixed` or `stratified` water, `lead:<group>`, night, storm, upwelling, runoff, tide, bloom, crash, milky, scum, hypoxia, cysts) explain what is happening now: half the bubbles pick one that fits. A topic's `why` facts come first 70% of the time. 46 added (30 with `when`), each true of the sea and of the model, sources checked.

Text uses only the pixel font's characters (it is uppercased and filtered on load). Every fact is true, sourced, and never contradicts the model.

## Build phases

**One phase per session. Do not start the next phase. Each phase must look/sound good before moving on. Commit with git after each phase.**

The order was changed with the author (visuals first): the world's cycles and coupling come before sound.

1. **Silent world** ✅ — RNG, fixed timestep, fields, cells, rules 1–4, pixel renderer, background, HUD, debug overlay, camera/zoom, cell forms. No audio.
   *Done when*: a 10-minute run shows the population rising and falling without extinction or explosion, it looks charming at pixel level, and it holds 60 fps on a phone (frames are only drawn when a tick ran, so in practice: no dropped ticks and frame work under 8 ms at p95).
   `node tools/sim-check.mjs [seeds] [minutes]` fast-forwards many seeds headlessly to check population behaviour, nutrient conservation and determinism.
2. **Cycles** ✅ — diel light (one day 5 minutes by default, `?day=5|10|30`), night rest, **night descent** (approved local rule: in darkness cells follow the nutrient gradient down instead of seeking light; phototaxis pulls them back up at dawn, giving diel vertical migration), nutrient pulses, grazing (rule 5). Day/night is shown by **palette shifts**: a few hand-curated palettes (day with deep rays, golden evening, moonlit night where bioluminescence glows, dawn) crossfaded by dithering, so every frame still uses only curated colours. Each keyframe hand-picks the environment colours (**and the season**, author 2026-10-22: each keyframe has a hand-picked winter twin, colder and bluer, steel-blue water and paler rays; today's colours are summer's; spring and autumn are two fixed steps between, following the air's warmth, and the colours dither only over the last 15% of the way from one step to the next, so most of the year is flat colour); pigments keep their ramps (at night each tone takes the next darker step), so lineages keep their colour at every hour.
   *Done when*: a 30-minute run contains at least one bloom, a die-off and a recovery, and migration is visible.
3. **Coupling and chains** ✅ — rule 6 (Kuramoto, K = 0.9 rad/s over neighbours within 10 units: kin lock, strangers drift, so several colonies pulse at their own tempos), visible as synchronised flashing and flagella beating together, plus **chain adhesion** (approved local rule: on division daughters may stay linked by a spring, inserted next to the mother so a chain grows from within, more likely with high `coupling` from the point where setae appear, like setae interlocking in *Chaetoceros*; the form sets the length: diatoms up to 8, *Alexandrium* and *Tripos* 2–4 (author: *Dinophysis* and *Prorocentrum* don't chain), soft flagellates never; links break when a cell dies or slowly at random, and a chain is one species: a cell a mutation has carried into another form lets go of its neighbours, 2026-10-23, after the author saw mixed-species chains). **Chains are a size refuge from the small grazers**: grazing risk × 1/(1 + 1.5·(length − 1)); sardines and salps filter chains like anything else. **Colony habits** (artistic liberty, author-approved): some glass-diatom lineages build shaped colonies — each joint turns by a fixed angle, so the same springs make straight chains (*Chaetoceros*), coils that close into rings (*C. curvisetus*, box cells) or snowflake stars of pennates radiating from a hub (*Asterionellopsis*). The habit comes from the lineage's sprite seed and form, is fixed when the colony is founded, and is inherited by every daughter born into it. A colony diffuses as one body: its cells share one Brownian kick (÷√length). Chains are drawn swimming and turning as one, cells stacked along the chain (dinoflagellates apex to antapex, pennates end to end, round and box cells valve to valve), with interlocking setae bridging the gaps.
   *Done when*: you can see clusters and chains synchronise, nobody coded.
4. **Harmonic field + voices** ✅ — harmony, audio chain, voice budget, and rule 7 (pitch attraction). Cells sing when they flash.
   *Done when*: 10 minutes of listening are never harsh, never mush, include stretches of near-silence, and synchronised clusters are heard as chords nobody coded.
5. **Elders** ✅ — cells that survive long in deep, low-light water slow their metabolism, grow, and sing low drones. The oldest living elder sets the harmonic root; when it dies, the root may shift.
   *Done when*: root changes are rare and feel like events.
   As built: **dark acclimation** (approved local rule): days spent in deep, dim water (light profile < 0.12, about the lower half of the column; judged by day only) slowly make a cell an elder (0..1 over ~3.3 min of daylight; fades at half that rate in brighter water). Its uptake and upkeep slow by 80%, ageing by 95%, its pulse by 75%, its swimming by 90% (it settles where it is), it stores energy up to 3× before dividing (division halves its elder level) and it is drawn up to 1.5× larger and darker, so it also sings lower. Elders die of old age after ~10–20 min as elders; that is fine (author). Elders (≥ 0.6) drone instead of singing tunes: a sine sub (C1–B1) with soft octave and twelfth pad partials under a filter that opens through a 6–10 s swell and closes through a 16–28 s fade, at most 3 at once, with a slow wide ring. Soft cells singing within 30 units of a droning elder hold their notes 2.5× longer with slower attacks: the pads. **The root**: the oldest full elder holds it; when it dies or stops being an elder, the next oldest takes it and its own note becomes the new tonal centre (the whole water modulates; the new holder drones at once). A new key holds at least 3 min; a holder appointed sooner adopts it. Measured: first elder at ~5–10 min (author asked for sooner), 3–6 key changes per hour, drones 30–80% of the time, ecosystem unchanged (no extinctions, blooms and recoveries in every seed).
6. **The hand in the water** ✅ — tap to scatter, swipe to strum (toward the light opens the filter, the deep closes it), sideways makes the filter ring (see above).
   *Done when*: playing and watching both feel complete, and stopping lets the water drift back on its own.

## Never
- Never add UI panels, knobs, menus or settings screens.
- Never add new cell types or scripted events. Propose a local rule instead.
- Never add a gene the listener can't perceive.
- Never make the ecosystem react fast. Responses take seconds; blooms take minutes.
- Never allow more than one tonal centre at a time.
- Never use colours outside the palette, blur, or smooth canvas gradients.
- Never refactor or rename things outside the current phase without asking.
- Never leave `console.log` in committed code.
